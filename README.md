# 🏭 Urban Lab Rimini - Monopattino del Futuro

## 📋 Descrizione
Progetto del monopattino elettrico del futuro sviluppato da **Urban Lab di Rimini** (Via Bonsi) in collaborazione con **MyZubster**.

## 🎯 Obiettivi
- 🛴 Progettare un monopattino elettrico innovativo
- 🧠 Integrare AI (Pytho + ChatGPT)
- 📡 Creare un sistema di monitoraggio intelligente
- 🎤 Sviluppare un assistente vocale
- 🔧 Realizzare un prototipo funzionante

## 🔧 Componenti Principali

| Componente | Specifiche | Costo |
|------------|------------|-------|
| Telaio | Fibra di carbonio 120x40cm | €450 |
| Motore | Brushless 800W 48V | €180 |
| Batteria | LiFePO4 48V 20Ah | €320 |
| Controller | VESC 60A 12S | €85 |
| Ruote | 10" pneumatiche | €185 |
| Freni | Idraulici 160mm | €85 |
| Sospensioni | Forcella ammortizzata | €95 |
| Elettronica | ESP32 + Sensori | €110 |
| **TOTALE** | | **€1,510** |
