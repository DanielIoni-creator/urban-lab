# 🌀 MACCHINA DEL TEMPO - HARDWARE

## 🔩 COMPONENTI PRINCIPALI

### 1. Struttura Meccanica
- Telaio in alluminio 6061-T6
- Pannelli di fibra di carbonio
- Sistemi di fissaggio in acciaio inox

### 2. Sistema Elettromagnetico
- Bobine di Tesla (per generare campi torsionali)
- Magneti permanenti al neodimio N52
- Condensatori ad alta tensione

### 3. Sistema di Controllo
- Raspberry Pi 5 (cervello centrale)
- Arduino Mega (controllo periferiche)
- Schermo OLED per interfaccia

### 4. Sensori
- Sensori di campo magnetico (Hall effect)
- Sensori di temperatura e umidità
- Accelerometro e giroscopio

### 5. Alimentazione
- Batteria LiFePO4 48V 100Ah
- Pannelli solari per ricarica
- Sistema di backup a condensatori

## 📋 SPECIFICHE TECNICHE

| Componente | Specifica | Quantità |
|------------|-----------|----------|
| Bobina di Tesla | 100kV, 50kHz | 1 |
| Magneti N52 | 5x5x5cm | 8 |
| Condensatori | 1000µF, 450V | 10 |

| OLED Display | 7" | 1 |

- Tensione operativa: 48V DC
