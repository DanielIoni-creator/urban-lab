# 🔧 POSTAZIONE DI LAVORO - MACCHINA DEL TEMPO

## 📋 PREPARAZIONE AREA

### Spazio di lavoro
- [ ] Tavolo robusto (min 150x100cm)
- [ ] Buona illuminazione
- [ ] Prese elettriche disponibili
- [ ] Area ben ventilata

### Attrezzatura di sicurezza
- [ ] Guanti isolanti (per alta tensione)
- [ ] Occhiali di sicurezza
- [ ] Tappetino antistatico
- [ ] Estintore (classe C)

### Strumenti base
- [ ] Cacciaviti (taglio e stella)
- [ ] Chiavi brugola (2-8mm)
- [ ] Pinze (taglio e presa)
- [ ] Tronchesi
- [ ] Spellacavi
- [ ] Metro/calibro

### Strumenti elettronici
- [ ] Stazione saldatura (min 60W)
- [ ] Multimetro digitale
- [ ] Oscilloscopio (opzionale)
- [ ] Alimentatore variabile
- [ ] Saldatore a stagno

### Materiali di consumo
- [ ] Stagno per saldatura
- [ ] Flussante
- [ ] Nastro isolante
- [ ] Fascette per cavi
- [ ] Termorestringente
- [ ] Colla a caldo
